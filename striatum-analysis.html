4 · Resume and export

Automatic resume: completed, skipped, and in-progress tracings are stored in this browser. Re-select the same batch after reopening the page to continue. Exporting a project JSON provides an additional portable backup.

Result ZIP: contains ROIs, CSVfiles, processing_log.csv, skipped_images.txt, and project metadata. Each ROI set is an ImageJ-compatible ZIP containing the three arrows and three rectangles. ND2 decoding uses a browser Python/WebAssembly runtime downloaded on first use; images are not uploaded.
